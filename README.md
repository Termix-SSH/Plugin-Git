## Overview

Git shows and manages the git repos on your hosts over SSH. Each host gets its own tab with its repos, their changes, branches and history, and auto pull keeps them up to date. It uses the keys and git settings of the host's login user, so Termix stores no git secrets.

Read the [docs](https://docs.termix.site/plugins/git) to set it up and use it.

<br />

## Features

- Add the git repos on a host, or find them with a scan
- Branch, ahead and behind counts, changed files and the last commit for each repo
- Diffs, staging, commits, history and commit details
- Fetch, pull, push, switch, create, merge and delete branches, stash
- Clone a repo onto the host
- Auto pull on a schedule with an optional command after a pull and alerts when it fails
- Uses the keys and git settings of the host's login user, no secrets stored in Termix
- A Git panel beside terminals, a dashboard card and status tiles for Operations Center
